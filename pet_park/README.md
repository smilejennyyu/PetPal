# Pet Park

A two-pet show, written by two programmers.

Run it with:

    python park.py

## How this repo works

- `park.py` — the show. **Shared.** Both of us edit it, so:
  `git pull` before you start, `git push` when you finish.
- `tricks_a.py` — belongs to one person. Nobody else touches it.
- `tricks_b.py` — belongs to the other person. Nobody else touches it.
- `petpal.py` — the engine. Nobody edits it, ever.
